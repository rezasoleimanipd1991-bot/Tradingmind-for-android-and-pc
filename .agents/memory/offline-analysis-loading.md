name: بارگذاری تحلیل آفلاین
description: رفتار مقاوم صفحه اجرای تحلیل در برابر داده‌های ناقص یا مهاجرت‌نشده IndexedDB
---

در برنامه‌های آفلاین، وجود استراتژی یا جلسه به‌تنهایی تضمین نمی‌کند که فازها و گام‌های فرزند هم وجود داشته باشند. صفحه اجرای تحلیل باید برای رکورد ناقص، جلسه حذف‌شده، JSON خراب و استراتژی بدون فاز حالت خطای قابل‌تلاش‌مجدد نشان دهد و هرگز نبود داده را با loading دائمی پنهان نکند.

**Why:** IndexedDB روی دستگاه‌های قدیمی، نسخه‌های قبلی schema و restoreهای ناقص می‌تواند parent را نگه دارد ولی child record را نداشته باشد؛ این حالت روی موبایل بسیار شبیه freeze دیده می‌شود.

**How to apply:** هنگام افزودن مدل‌های جدیدِ parent/child، هم migration/seed را بررسی کن و هم مسیر runner را با loading، error، retry و پیام راهنما پیاده‌سازی و روی viewport موبایل بررسی کن.
